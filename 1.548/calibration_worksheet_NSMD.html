Engineer comments:
Prototype calculation rules: digital reference thermometer dropdown fills the cal due date automatically; correction and reference maths rounded to 3 decimal places; Display cycle, Display from product and Room Temperature average rounded to 1 decimal place (0 when the unit's Display is set to "No decimal point") using improved robust mathematical rounding across all fields. Select the probe from the dropdown; the nearest correction to the Initial Set Point is used for As Found, and the nearest correction to the Final Set Point is used for As Left. Display from product is calculated from Display cycle Max and Min. Air reference average uses the highest corrected maximum and the lowest corrected minimum; those two values are visibly marked in the table. Every column heading shows the tolerance actually in force for it, taken from the same functions the calculation uses, so the figure shown and the figure applied can never differ. Air is ±0.300 °C in Standard, widening to ±1.000 °C only for Air itself under "No Decimal Point"; Load and a Standard Chart Recorder are always ±0.300 °C and always entered to one decimal place, exactly as on the Standard Medical Device form; a linked Chart Recorder inherits the tolerance of whichever column it is based on. A column with no product display shows "No Display" rather than a tolerance, because there is no comparison to judge. Adjustment not needed is applied only when every column that actually has a display comparison is within its own tolerance — a column with no display is excluded from that decision entirely, never counted as a pass, a fail, or a zero difference. "Load Fitted No Display" keeps Load's probe, Reference Max/Min, corrections and Average fully live and required, and marks N/A only the Load Display, the Load Display cycle and the Difference vs Display, since there is no product display on Load to compare against. A Chart Recorder "Based on Air Readings" or "Digital Chart Recorder Based on Air" has no probe of its own: it shares the Air measurement system, so its column shows the same two channels — Air Left → Chart Left, Air Right → Chart Right — with every reference figure mirrored across read-only. "Digital Chart Recorder Based on Load" mirrors Load's figures the same way, as a single channel. All mirrored values are re-linked on every change, never copied once. Air, Load and Chart Recorder each have their own settings in the As Found table header, and none can be left on "-- select --" once you start entering readings; an absent column is greyed out, not required for validation or PDF generation, and left out of every calculation. If any active result is missing or outside tolerance, As Left remains active and must be completed.
